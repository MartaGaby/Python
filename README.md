🐍 Exercícios Básicos em Python

Este repositório contém a minha resolução da lista Exercícios Básicos em Python, com foco em praticar lógica de programação, estruturas de repetição e condições.

📘 Conteúdo

Os exercícios incluem:
Operações matemáticas (soma, média, dobro de número)
Estruturas de repetição (tabuada, fatorial, contagem)
Condicionais (maior número, classificação etária, nota para conceito)

🚀 Objetivo

Fixar a lógica de programação em Python
Ajudar iniciantes que estão começando na linguagem
Compartilhar aprendizado e boas práticas
